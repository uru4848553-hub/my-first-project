どの回も同じ型（`make_shorts_2to5.py` の先頭の説明）。変えているのはテーマだけなので、再生数の差＝テーマの差として比べられる。

## 1本の作り方
1. フォルダを PC にコピーする
2. `script.md` の本文を ElevenLabs などで読み上げ、mp3 を `audio/` に1本入れる
   - 「テロップ：」「効果音：」「//」で始まる行は読ませない
   - 低めで落ち着いた男性の声、ややゆっくり。**最初の一言（S01）は1秒以内に言い切る**ので、S01 の文のあとに少し間を空けてもよい
3. `.\run.bat autoedit.py "<フォルダ>" --motion alternate` で Resolve に組み上げる
   - V1：映像（S01・S02 は動く mp4、ほかは画像にゆっくりズーム）、V2：テロップ（Text+）、A1：ナレーション、A2：効果音
4. `プレビュー_ナレーションなし.mp4` は確認用（テロップは仮の表示、効果音入り）

## 素材を作り直すとき
```
python channel_produce/shorts/make_short01.py          # 1本目
python channel_produce/shorts/make_shorts_2to5.py      # 2〜5本目（番号を付けるとその回だけ：... 3）
```
絵の部品は `blueprint.py`、効果音は `sfx.py`（ffmpeg で合成した自作の音）。

## 投稿後に見る数字（24時間以上たってから）
冒頭3秒の維持率／平均再生率（ループで100%超え）／コメント数。5本そろったら上位2つのテーマを長尺にする。
