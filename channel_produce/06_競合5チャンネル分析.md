## 2. 分かったこと（重要な順）

### ① このジャンルは「今まさにブーム」。しかも競争が始まった
- 夜ふかし解剖室（10/3）、のら学者（10/4）、レグラボ（10/6）が**同じ週に始まっている**。研究とデータで「差」を語るチャンネルが一斉に出てきた
- 良い知らせ：**今伸びている市場**である証拠（3つとも6〜7週で数十万〜数百万再生）
- 悪い知らせ：**似たチャンネルが毎月増える**。同じテーマ・同じ見た目だと埋もれる。**早く出すことと、はっきり違う見た目と切り口**が必要

### ② 本数ではなく「テーマ選び」で決まる
- **レグラボ：23本で173万再生**（1本あたり平均7.5万）
- **浮き世の解剖ラボ：129本で99万再生**（中央値はたった729回）
  - 古い動画は「なぜ人は『忙しい』を自慢するのか」「なぜ日本人は休むことに罪悪感を持つのか」のような**一般的な心理の話**で、再生は50〜70回
  - 「世帯年収1,500万」「富裕層」「年収で見える世界」に変えてから、1万〜12万回に伸びた
- のら学者も、最初の10本ほどは数百回。「独身の老後」「Z世代と氷河期」「弱者男性」から伸び始めた
- → **間違ったテーマで100本出しても伸びない。正しいテーマなら20本で伸びる**。最初から実証済みのテーマだけを選ぶのが、いちばんの近道

### ⑤ タイトルの工夫
- **【学問の名前】を付ける**：レグラボ【組織行動学】【行動経済学】、浮き世【行動経済学・社会心理学】、大神【社会心理学】【科学的根拠あり】。「ただの意見ではない」と一目で分かる。夜ふかし解剖室は付けていない → **自分のチャンネルで試す価値がある**
- **数字を入れる**：「890万人」「7人に1人」「38歳から75歳まで」「S・A・B・C」
- 浮き世の「9割が知らない〜」は一時的に伸びたが、似た言い回しが多く、チャンネルの信用を下げやすい（使わない）

### ⑥ ショートは、このジャンルではほとんど伸びていない
- 6チャンネルのうち、ショートを出しているのは大神さんだけ
- 大神さんのショート103本の中央値は**6,900回**（長尺の中央値は4.65万回）。登録者12.5万人のチャンネルでも、ショートは長尺の1/7
- → **このジャンルの主戦場は長尺**。これまでの「ショートで反応を見て長尺にする」計画は、**主力を長尺に切り替える**（ショートは役割を絞る。下の8章）

### ⑦ 長さ
- 当たっている動画は **9〜23分**。レグラボは **10分前後**で数十万再生
- 夜ふかし解剖室の最近の動画は28〜31分に伸びたが、伸びは落ちている（新しい1/4の中央値 4.6万→3.8万）
- → **10〜15分を基本**にする（制作の負担も半分になる）

### ⑧ 登録率はどこも低い
- 1登録あたりの再生は115〜380回。どのチャンネルも**おすすめから見られていて、ファンになる人は少ない**
- → 伸びるかどうかは「テーマ・タイトル・サムネ」でほぼ決まる。登録を増やすには、同じ登場人物・同じ締めの言葉で「シリーズ」として覚えてもらう工夫が必要（夜ふかし解剖室の黒猫のように）

## 4. 新チャンネル「人生の断面図」への反映

### ① 主力を長尺に切り替える
- **長尺：週2本（10〜15分）を主力**にする
- ショート：作った5本は予定どおり出す（テーマの反応を見るため）。ただし、その後は**長尺の一番強い場面を切り出すだけ**にし、ショート専用の新作は作らない
- 長尺が8〜10本たまったら、**1〜2時間の「聞き流し総集編」**を作る（夜・睡眠用。新しく作らずに総再生時間を伸ばせる）

### ② テーマの優先順位（6チャンネルの実績順）
1. **年収・世帯年収**（3チャンネルで当たり）← 長尺第1弾（年収と時間）はこのまま
2. **会社の中の差**：役職別（平社員・係長・課長・部長）、人事評価別、会社の大きさ別。**レグラボが10分で数十万回**。ヒロキさんの会社員25年の経験が一番活きる。**ビルの4つの階＝会社の4つの役職**で、チャンネルの見た目とも合う
3. **世代**（Z世代と氷河期世代の対比）
4. **IQ・頭の良さ**
5. **将来の不安を1人の一生で追う**：「年収300万円の独身男性を、統計で40歳から80歳まで」など（のら学者の型。ただし「独身の老後」はのら学者がやったので、**別の人物と別の小物**で）
6. 富裕層・貯金

**やらないテーマ**：順位のない一般心理、抽象的な哲学・社会、ハウツー（年金・健康法）、雑談

### ③ 型は4つを使い分ける
| 型 | テーマ |
|---|---|
| 物語型（4人の階） | 年収、貯金、IQ |
| 年表型（世代ごと） | 世代、年代 |
| 比べる表型（同じ項目を階ごとに） | 会社の大きさ、役職、人事評価、学歴 |
| **人生の断面図型（1人の一生を年齢で切る）**＝新しく追加 | 老後、独身、氷河期世代の一生、年収300万円の一生 |

### ④ タイトルに【学問の名前】を付けるテストをする
- 例：「なぜ課長になると、急に仕事がつまらなくなるのか【組織行動学】」
- 最初の10本のうち5本に付けて、付けない5本と比べる（ほかの条件はなるべくそろえる）

### ⑤ ほかのチャンネルと違う見た目にする
- 夜ふかし（模型の部屋・黒猫）、浮き世・レグラボ・のら学者は、それぞれ別の見た目。人生の断面図は**「ビルの断面図＋紺の方眼紙」**で統一し、似せない
- 1人の一生の回も、**ビルの階＝年齢**（1階＝40代…4階＝75歳）にすれば、同じ見た目のまま使える

## 5. 「失敗しないチャンネル」は作れるか

**正直な答え：失敗する確率は大きく下げられる。ただし、ゼロにはできない。**

**下げられる理由**
- 6チャンネル・約800本の実績から、**当たるテーマと外れるテーマがはっきり分かった**。浮き世の解剖ラボが100本かけて学んだことを、最初から避けられる
- 実証済みの型が5つあり、そのうち「〇〇別 見えている世界」は3つのチャンネルで当たっている
- 長尺の台本、ショート5本、作業の自動化（自動配置ツール）がすでにある

**ゼロにできない理由**
- **競争がこれから激しくなる**：同じ週に3チャンネルが始まったように、似たチャンネルは今後も増える
- **YouTube のおすすめは読めない**：どのチャンネルも当たりは全体の1〜3割
- **作りの質**：同じテーマでも、台本・絵・声の出来で再生数は何倍も変わる

**失敗しないためのルール**（毎回確認する）
1. テーマは、上の「当たる」一覧に入っているものだけ
2. 段は3〜4つ（または1人の一生を年齢で）。数字かラベルを付ける
3. 下の段の人を責めない。どの段にも強みを書く。最後は救いで終える
4. 研究・統計は公的なものか論文。概要欄に出典
5. 長尺は10〜15分。冒頭1分で「何が分かるか」を約束する
6. 1本ずつで判断しない。**10本ごとに**数字を見る

**撤退・方向転換の目安**
- **長尺10本**で、1万回を超える動画が1本もない → テーマ・サムネ・タイトルのどれかが合っていない。上位チャンネルのサムネと並べて見直す
- **長尺20本**で、10万回を超える動画が1本もない → 型を変える（例：物語型から人生の断面図型へ）
- 浮き世の解剖ラボのように、外れテーマを100本続けることだけは避ける
