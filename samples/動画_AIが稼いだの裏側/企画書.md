### 元動画を使うときの注意（引用のルール）
他人の動画は、そのまま使うと著作権の問題や YouTube の Content ID（自動の権利チェック）に引っかかることがある。日本の著作権法の「引用」として使うために、次を守る（法律の助言ではなく、一般に言われている目安）：
1. **自分の説明が主、引用は従**：元動画は1か所3〜5秒、合計15秒以内。動画の大部分は自分の図解とナレーション
2. **引用だと分かるようにする**：元動画の部分は枠で囲むか、画面の一部に小さく入れる
3. **出典を出す**：画面に「出典：The Koerner Office（YouTube）」などを表示。概要欄にも2本のURLを書く
4. **改変しない**：切り抜くだけ。発言の意味が変わる編集はしない
5. **音は使わない**：元動画の音声は流さず、日本語字幕＋自分のナレーションにする（自動配置ツールも動画の音声は置かない）

不安な場合は、元動画の映像を使わず「タイトル画面の画面録画（2秒）＋出典表示」だけにしても成立する。

### 改善版2で変えたこと（2回目の厳しめチェックへの対応）
| 指摘 | 対応 |
|---|---|
| 「約2割」「約20件」の因果関係が分かりにくい | 「350通 → QRを読んだ約2割（68人）→ 人間の電話 → 約20件」を1本のフロー図とセリフでつないだ |
| 二択がありきたり。当事者意識を持たせたい | 「この最後の電話まで、AIがやる日は来ると思いますか？」に変更。「AIに仕事を奪われるか」という自分ごとで、来る／来ないに意見が割れる |
| 「AIが全自動で稼いだわけではない」ギャップをドラマチックに | 「ここからが裏側」の区切り＋「泥臭い電話」を赤字、効果音チーン |
| （こちらで修正）提案文「約2割がアクセスし、最後は人間が電話で営業」 | 元の話では、営業担当は反応した人だけでなく**リスト全員に電話**している。「反応した2割にだけ電話した」と受け取れる言い方を避け、「電話をかけ続けて」にした |
| （こちらで修正）提案文「その多くは仮想通貨の変動によるもの」 | 「変動（値上がり）」ではなく、**仮想通貨での売上・支払い**が約半分（ある時点で約19.5万ドル中 約9.5万ドル）。「売上のかなりの部分は仮想通貨」とした |
| （こちらで修正）提案の締め「あなたはどこまでAIに任せますか？」 | 指摘②（当事者意識の強い問い）と逆に、開いた問いに戻っていたため、上の「来ると思いますか？」を採用 |
| （こちらで修正）効果音5つ（ドン・シュッ・チーン・ピコッ・ポーン） | 教材の目安（1分でエフェクト最大3回）に合わせ、ドン・チーン・ポーンの3つに絞った |
