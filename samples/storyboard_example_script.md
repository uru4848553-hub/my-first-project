# 絵コンテ（8カット）を script.md に書き換えた例
// 「//」の行は読み上げない（テロップ・カメラの指示のメモ用）。## Sxx の下の文章がナレーション

## S01
// テロップ：ついに、想像を超えたiPhoneが来る。
// カメラ：9:16／24mmローアングル／左前から右背面へゆっくり半周オービット／側面アップで終了
ついに、私たちの想像を超えたiPhoneがやって来ます。

## S02
// テロップ：側面が開き、AIイヤホンが出現
// カメラ：85mmマクロ／側面の収納口へ急接近／カメラ固定／2個を時間差で押し出す
まず、本体の側面が開き、AIイヤホンが自動で現れます。

## S03
// テロップ：最大の売りは、先回りするAI
// カメラ：50mm／人物の斜め後方から肩越し／iPhone前面を正対／液晶画面にフォーカス
最大の売りは、触る前に動き出す、先回りAIです。

## S04
// テロップ：耳に装着した瞬間、AIが起動
// カメラ：50mm横顔／イヤホン装着済み／青いAIリングが起動／スマホは映さない
耳に装着した瞬間、予定も移動も、すべての準備が始まります。

## S05
// テロップ：朝の予定も体調も、先回り
// カメラ：35mm／人物の斜め後方から肩越し／iPhone前面を中央に大きく／液晶へフォーカス
起床、体調、予定を読み取り、朝の準備から先回りします。

## S06
// テロップ：仕事も移動も、自動で準備
// カメラ：28mm追跡／人物の斜め後方から肩越し／手持ちiPhone前面を正対／液晶へフォーカス
会議資料やメール、最適なルートまで、自動で準備します。

## S07
// テロップ：「撮って」だけで、3眼カメラが展開
// カメラ：85mmローアングルマクロ／カメラ固定＋微ドリーイン／3眼レンズを同時上昇
「撮って」の一言だけで、3眼カメラが展開し、自動撮影します。

## S08
// テロップ：これはスマホではない。AIの相棒だ。
// カメラ：24mm前面3/4から追従／人物の正面へ回り込み／本体アップでカット／ループ
これは、ただのスマホではない。あなたより先に考える、AIの相棒です。
