# 企画書：海外で流行中のAI受付副業、日本だと？

- チャンネル：ゼロからAI副業（ショート）／約30秒／顔出しなし／1本完結
- 伝えることは1つ：海外の副業は、そのまま日本に持ってきても通用するとは限らない（値段の感覚が違う）
- 作り方：元動画とネットで調べた料金だけで作る（ヒロキ自身の実践なし）。素材は元動画の短い引用、料金ページの画面録画、Canvaの図解
- 台本：`script.md`（自動配置ツール用）、`台本_読みやすい版.md`（説明付き）

## この企画ができた経緯
別の人が直した台本「海外で流行中のAI副業（月7万円モデル）」を厳しく見直した結果、次の問題があったため作り直した。
| 元の台本の問題 | この台本での対応 |
|---|---|
| 「月7万円」「日本なら月1万円」に出典がない | 海外は解説記事の「1件 月500〜2,000ドル」、日本はAI電話サービスの公式料金を使う |
| 日本ではお店が自分で月3,000円台からAI電話を入れられるのに、そこに触れていない | それを動画の一番の驚きにした |
| 「毎月7万円をもらい続ける」と「稼げる」から入っている | 「海外ではこの値段で売られている」という事実だけ。「稼げる」とは言わない |
| 「一度入れれば積み上がる」は言い過ぎ（営業・解約・サポートがある） | 言わない |
| 7万円 → 1万円の値下げが「釣り」に見える | 海外と日本の値段を並べて比べる形にした |
| 「月いくらでやる？」は答えにくい | 「日本で成り立つ？成り立たない？」の二択にした |
