# 企画書：AIに当てさせてみた #1「写真1枚で、AIは作り方を当てられるか」

リサーチの根拠：`research/2026-09_海外と日本のAIショート比較.md`（スキル hiroki-youtube-project-freedom の「2.8 海外と日本のショートの違い」にも追加済み）

## リサーチをどう入れたか

海外のAIショートが伸びるのは、視聴者数が多いからだけではなく、**作り方が違う**から。海外は「副業の説明」ではなく「驚きを見せる動画」で、1秒目に結果が見え、言葉が分からなくても楽しめる。日本のAIショートはニュースやツール解説が多く、前提知識がないと分からないので、AIに興味のない人はすぐスワイプする。

この企画では、海外の作り方を次のように持ち込む。

| 海外の作り方 | この企画での入れ方 |
|---|---|
| 説明ではなく驚きを見せる | 「AIの使い方」は説明しない。「写真1枚でAIはここまで分かるのか？」という驚きとクイズだけで見せる |
| 1秒目に結果（完成品）を見せる | **最初の1秒は、AIの答えが出た画面＋製品の「跡」に赤丸が付いた状態**から始める（答えが合っているかの判定は隠しておく）。そのあと撮影シーンに戻る |
| 言葉が分からなくても楽しめる | 答え合わせは「赤丸」「矢印」「◯ △ ✕ の大きなスタンプ」で見せる。音を消しても、何が当たって何が外れたか分かるようにする |
| 前提知識がいらない | AIの名前・専門用語は出さない（「射出成形」→「型に流し込む作り方」、「ゲート」→「流し込んだ入口の跡」） |
| 稼げるから入らない | お金の話は一切しない。副業へのつながりは最後の一言（「見抜けるかが、AIを仕事に使えるかの差」）だけ |
| 型だけ借りて中身は自分で | 海外の「ビフォーアフター」「結果を先に見せる」型を借り、中身はヒロキが実際にAIに聞いた結果。外れても盛らない |
| シリーズ化 | 「AIに当てさせてみた」#1、#2…と同じ型で続ける |
| 日本はAIを使う人が約3割 | 狙いはAIを使っていない約7割。「あなたも一緒に考えて」「あなたは何問当たった？」で、見る人をクイズに参加させる |

## 海外の作り方チェック（スキル2.8の7項目）

| # | 項目 | 判定 | 理由・直したところ |
|---|---|---|---|
| 1 | 驚きか | ○ | 「写真1枚でそこまで分かるの？」という驚き。外れた場合も「やっぱり無理」という意外性になる |
| 2 | 1秒目に結果 | ○（修正済み） | 最初の版は「撮る手元」から始まり、結果が9秒目まで出なかった → 1秒目をAIの答え＋赤丸の画面に変更 |
| 3 | 無音テスト | ○（修正済み） | 答え合わせを赤丸・矢印・◯△✕スタンプで見せる指示を追加 |
| 4 | 前提知識ゼロ | ○ | 専門用語は日常の言葉に置き換え、AIの名前も出さない |
| 5 | 稼げるから入らない | ○ | お金の話なし |
| 6 | 本当に試した中身 | ○ | 【】を実際の結果で埋めてから録音。経歴・自己PRは入れない |
| 7 | シリーズ・ループ | △ | シリーズは○。ループは入れない（クイズは答えを知ると2周目の理由が弱いため）。代わりに「あなたは何問当たった？」で参加とコメントを促す |

## 候補にした3案と選んだ理由

| | 案A：AIに当てさせてみた（採用） | 案B：AIを使ってない人ほど得する使い方3選 | 案C：AIへの頼み方のビフォーアフター |
|---|---|---|---|
| 借りた型 | 結果を先に見せる／決めつけ→結果（予想の逆）／クイズの答え合わせ | 海外の「知っているのが反則級」 | ビフォーアフター |
| 独自要素 | 実際にAIに聞いた結果＋物の「跡」で答え合わせ | 日本の生活向けの例 | 弱い（誰でも作れる） |
| 1秒目の分かりやすさ | 強い（身近な物＋AIの答え） | 強い | 中 |
| 被りにくさ | 高い | 低い（日本でも出回り始めている） | 低い |
| 副業とのつながり | 「AIの答えを見抜く目」＝AIで仕事をする力 | 薄め | 中 |

**案Aを採用。** 上のチェックを満たし、シリーズにしやすいため。案Bは型そのものが海外の王道なので、#2以降の候補として残す。

## 撮影の前にやること（台本の【】を埋める）
1. 家にあるプラスチック製品を1つ選ぶ（例：100均の収納ケース、ペットボトルのキャップ、洗濯ばさみ）。**裏側に丸い跡や、格子状の補強が見える物**だと答え合わせが目で分かりやすい。
2. 同じ写真をAIに送り、次の2問をそのまま聞く。画面は最初から録画しておく。
   - Q1「これはどうやって作られましたか？一言で」
   - Q2「なぜ裏側はこの形になっているのですか？一言で」
3. 答え合わせをする（正解／半分正解／不正解＋理由を1文）。理由はネットや製品の説明でも確かめる。
4. `script.md` の【】を、実際の答えと判定に書き換える。効果音の K02（正解）・K03（不正解）も結果に合わせる。
5. 当たりすぎ・外れすぎで面白くなければ、題材を替えて撮り直してよい。ただし **結果は変えない**。

- **BGM**：声100に対して10〜20程度。クイズ番組風の軽いもの（`bgm/` に1本）。
- **テロップ**：5〜7文字で読める長さを意識。判定は「正解」「半分正解」「不正解」を色分け（正解＝白、不正解＝赤など）。色は Resolve で後から変える。
- **赤丸・矢印・スタンプ**：自動配置ツールは入れないので、S01・S03b・S04b の素材を作るときに入れておくか、Resolve で最後に足す。
- **確認**：書き出したら音を消して1回見て、何が起きているか分かるか確かめる（無音テスト）。

## 作り方（自動配置ツールを使う場合）
1. このフォルダを Windows の作業場所にコピーし、`script.md` の【】を書き換える。
2. 上の表どおり `media/` に素材、`se/` に効果音、`bgm/` に BGM を1本置く。
3. `script.md` の本文を読み上げて `audio/` に1本入れる。
4. いつもの手順で実行し、Resolve で確認して書き出す。

> 開発環境で確認したのは台本の読み取り（エラー0・警告0、6シーン8セクション、テロップ・効果音の指示も認識）まで。【】を書き換えたあとも同じ書式なら読めます。
