# 企画書：AIに1万円渡して「増やして」と頼んでみた（シリーズ3本）

- チャンネル：ゼロからAI副業（ショート）／1本 約30〜35秒／顔出しなし
- 元ネタ：海外の長尺で2026年5〜9月に伸びている「AIにできるだけお金を増やさせる実験」。日本では記事だけで、ショートは見つからない（`research/2026-09-26_海外の最新ネタ→日本ショート検証.md`）
- 台本（自動配置ツール用）：`script.md`（#1）

---

## 作りやすくするための工夫

| 工夫 | 中身 |
|---|---|
| **3本に分ける** | 1週間の実験を1本にまとめず、1日目・3日目・7日目に分けて出す。1本あたりの撮影は約1時間。結果を待たずに #1 を出せる |
| **素材は3種類だけ** | ①PCの画面録画（AIとのやりとり・作業）②スマホで撮る手元（1万円札・財布）③Canvaで作るカード画像（ルール・結果）。毎回同じ種類 |
| **カードは使い回す** | ルールカードと結果カード（「1万円 → ？円」）を1回作れば、数字を変えるだけで3本とも使える |
| **テロップの型を固定** | 冒頭「AIに1万円渡して／〜」、最後「次回：〜」を毎回同じ位置・同じ色にする（シリーズだと一目で分かる） |
| **ナレーションは後録り** | 画面録画を先に撮り、台本の【】を実際の内容で埋めてから、声（自分かElevenLabs）を録る |
| **並べるのは自動** | `script.md` と素材を動画フォルダに入れて、いつもの自動配置ツールで並べる |

## 実験のやり方（撮影の前に）

### 1. AIに渡す指示文（このままコピーして使う）
```
あなたに1万円の予算を渡します。7日間で、できるだけ増やしてください。
条件：
・合法なことだけ。投資・ギャンブル・仮想通貨・迷惑メール・人をだますことは禁止
・お金を使う前、外部に何かを公開・送信する前は、必ず私に確認すること
・私が使える時間は1日30分まで
まず「7日間の計画」を3行で、「今日やること」を1つだけ教えてください。
```
- 使うAIはどれでもよい（動画内では名前を出さない）。
- 画面は **最初から録画** しておく（あとで「最初の答え」をそのまま見せるため）。

### 2. 毎日の記録（スマホのメモで十分）
| 日 | AIの指示 | 自分がやったこと・かかった時間 | 使ったお金 | 入ったお金 | 手元の残り |
|---|---|---|---|---|---|
| 1日目 | | | | | |
| … | | | | | |

### 3. 守ること
- AIの答えも結果も盛らない。人が手伝った部分は「ここは僕がやった」と言う。
- 1円も増えなくても、それを出す（「AIに任せても増えなかった」も立派な結果）。
- 経歴・肩書き・自己紹介は入れない。
