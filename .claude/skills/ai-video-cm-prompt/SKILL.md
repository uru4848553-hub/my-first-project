# 動画生成AIの商品CMプロンプト

短い商品CM（主に5秒・縦長9:16）を、動画生成AIだけで破綻なく、かつ最初の0.5秒で指を止める映像にするための決まりごと。

## 1. 大きな変化は1つだけ（破綻を防ぐ）

5秒の中に複雑な自然現象（水流・植物の成長・日の出・光の屈折・煙など）を詰め込むと、AIは必ず崩れる。水が不気味に変形し、「動かさない」と指定した商品まで歪む。

- **大きな変化は1本のCMにつき1つ**（例：水が静かに広がる）。同時に起こす動きは多くても2つ（例：水の広がり＋光）
- 1秒あたりに入れる出来事は1つまで。0.5〜2秒のような短い区間に3つ以上の変化を書かない
- 「次々と開く」「一気に覆い尽くす」「爆発する」など、量や速さが大きい言葉は崩れの元。「静かに広がる」「ゆっくり光を放つ」のように、速さと量を抑えた言葉にする
- 商品（ボトル・パッケージ・ラベル）は固定。周りの変化が激しいほど商品も崩れるので、変化はおだやかにする
- 商品の中身（液体が光る）と足元（水が広がる）を変えると、AIが「商品が浮く」「水に沈む」と取り違えやすい。**商品の固定（アンカー）は強く、くり返し書く**：「石像のように微動だにしない」「置かれた場所・位置・大きさ・傾きは最初から最後まで一切変わらない」「水はボトルの周りを流れるだけで、ボトルは浮かず沈まない」。そのうえで「変わるのは周りの環境と光だけ」と対比させる
- 書く前に「この区間で動いているものはいくつあるか」を数え、多ければ削る

## 2. 文字（コピー）は0秒から出す（離脱を防ぐ）

離脱する人の視聴時間は1〜2秒。3秒目で文字を出しても、その前に大半がスワイプする。音なしで見ている人も多いので、0.5秒以内に「何の映像か」が文字で分からないといけない。

- コピーは**最初のフレームから画面に静止して置く**。後からふわっと出す演出にしない
- 編集ソフトを使わない前提のときは、動画のプロンプトの中で「0秒から画面上部に静止して表示」とコピーの文字を指定する（文字を「」でくくり、位置・書体・行数も書く）
- 文字は動かさない（動く文字はほぼ確実に崩れる）。短く、2行まで。大きく、商品に重ねない
- 動画AIは、映像を動かす途中で文字をウネらせたり、溶かしたり、別の字に化けさせたりしやすい。一般には「文字なしで生成して、編集アプリで文字を重ねる」のが一番確実。ただし**ユーザーが「編集ソフトを使わない」と決めているときは、その決定を優先し、編集アプリを勧めない**。その場合は次の書き方で崩れを減らす
  - 文字を「映像の外側に貼り付けた、平らな文字の層」として書く（例：「画面の手前に貼り付けた平面の文字として、映像の動きや光の影響を一切受けない」）
  - 文字の周りの空は動かさない（文字の後ろで雲や光が動くと、文字も一緒に崩れやすい）
  - 3〜4本生成して、文字が正しいものを選ぶ前提で伝える
- 生成後は、文字が一字一句正しいか、途中で崩れていないかを必ず確かめる
- 「最初から表示」と書いても、AIは文字を0.5秒ほどかけてフェードインさせがち。「0フレーム目からくっきり100%の濃さで表示。フェードインさせない」とはっきり書く

## 2-2. フックの発光は「スイッチ」で書く

「パッと光る」と書いても、AIは1〜5秒かけてじわじわ明るくする（実測：最初の1秒は画面の明るさがほぼ変わらなかった）。

- 「0.2秒で、スイッチを入れたように一瞬で最大の明るさになる」のように、時間と速さを数字で書く
- 光る前を暗くして差をつける：「最初のフレームは暗く、液体も暗い」→「一瞬で強く光る」→「少しだけ落ち着いて光り続ける」
- 光は液体だけ。ボトルの外まで光をあふれさせるとラベルが飛ぶので、「ラベルは読める明るさのまま」と添える

## 2-3. 音も同じプロンプトで指定する

編集ソフトを使わない場合、音も動画AIに作らせるしかない。何も書かないと汎用的な音になり、終わりに向けて消えていく（実測：最後は-58dBでほぼ無音）。

- 音の流れを時間つきで書く：0秒は静寂 → 発光と同時に澄んだ高い金属音（チャイム・ベル）か低音の一撃 → 水が広がる静かな音 → 上品なアンビエント
- 最後まで音を切らさない（ループ再生や次のカットへのつなぎのため）
- 声・歌・ナレーションは入れないと書く（後で自分のナレーションを乗せるため）

## 3. 引き算で高級感を出す

高級ブランドのCMは要素が少ない。背景・水・光・植物・文字…と足していくと、ファンタジー映画の予告編のようにガチャガチャする。

- 画面の要素は「商品＋背景1つ＋光＋コピー」程度に絞る。飾り（花・葉・小物）は足さない
- 背景の変化も1つ（例：乾いた地面が潤う）。空・植物・砂など、複数の場所を同時に変えない
- 余白を大きく取る。最後の1秒はほぼ静止して、商品が映える画で終わる
- ただし**完全には止めない**。止まりすぎると静止画やフリーズに見える。最後の1秒にも「ボトルを透過する光の筋がごくわずかにゆらめく」「水面に小さな光の反射が動く」くらいの微細な動きを1つ残す（ライブ感）

## 4. 5秒の型

| 時間 | 役割 | 書くこと |
|---|---|---|
| 0〜0.5秒 | フック | 最初のフレームからすぐ動く。商品に1つだけ強い変化（例：液体が光る）。コピーはすでに表示されている |
| 0.5〜3秒 | 展開 | 大きな変化を1つだけ、おだやかに（例：足元から水が静かに広がる）。光は添える程度 |
| 3〜5秒 | 余韻 | 静まる。最後の1秒はほぼ静止だが、光のゆらめきなど微細な動きを1つ残す |

## 5. プロンプトの書き方

- ユーザーが1回でコピーできるよう、**動画のプロンプトは1つのコードブロックにまとめる**。避けることも同じブロックの最後に【避けること】として入れる
- ユーザーが日本語を望むときは、すべて日本語で書く
- 必ず入れる固定の指示：カメラ固定／商品は石像のように固定（位置・大きさ・傾きを変えない、浮かない・沈まない）／商品の形・色・ラベルを変えない／コピー以外の文字を入れない／文字を崩さない・動かさない／人物や物を追加しない／ちらつかせない
- 光が強いと、商品の液体の色が夕日などの色に引っぱられる。「液体は元の色のまま。オレンジ色にしない」のように、商品の色を指定して打ち消す
- **ユーザーに渡すプロンプトは、常に1ブロックだけにする**。「先に画像を作って、次に動画」のような2段階の手順にしない。手元の商品画像1枚をアップロードし、そのプロンプト1つで完結する形にする（商品画像は「参照」として使い、最初の場面・コピー・変化はすべてプロンプトに書く）
- コピー入りの最初のフレームを別に作るやり方は崩れにくいが、手順が増える。ユーザーが求めたときだけ提案する

## 6. 出す前の確認

- [ ] 大きな変化は1つか。同時に動くものは2つ以下か
- [ ] コピーは0秒から表示されているか
- [ ] 画面の要素は少ないか（飾りを足していないか）
- [ ] 商品・カメラの固定、文字を崩さない指示が入っているか
- [ ] 商品の固定（石像のように、浮かない・沈まない）を強く書いたか
- [ ] 最後の1秒に微細な動きを1つ残したか
- [ ] ユーザーが決めた制約（編集ソフトを使わない など）に反する提案をしていないか
- [ ] 動画のプロンプトは1ブロックでコピーできるか

## 7. 生成後の確認（ユーザーに伝える）

- ラベルとコピーの文字が、途中で揺れたり崩れたりしていないか。**0フレーム目のラベルも見る**（アップロード画像を読み込んだ時点で「HERMÈS」が「HERMDS」になるなど、動き以前に崩れることがある。その場合はアップロードする画像を、ラベルがくっきり読める元の写真に替える）
- コピーが0フレーム目から出ているか（フェードインしていないか）
- 最初の0.5秒で、明るさがはっきり変わっているか
- 音が最後まで続いているか
- 商品の色が変わっていないか
- 商品が動いたり伸びたりしていないか
- 3〜4本生成して一番良いものを選ぶ前提で考える
