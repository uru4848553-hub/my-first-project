# ショート5本：タイトル・説明欄・サムネイル

## 共通ルール

**タイトル**（法則4・19）
- 「なぜ〇〇は、〜のか」の問いの形。答えは書かない
- 40文字以内（スマホで切れない長さ）。最後に `#shorts`
- 候補は3つずつ。**◎が本命**。1つのテーマで A/B を試すなら、24時間以上あけて別の日にする

**説明欄**
- 1〜2行目：動画の中身を一言で（検索とおすすめ用）
- 「あなたは何階？」の問いかけ（コメント誘導）
- 出典（論文名）と「研究は平均の傾向です／登場人物は架空です」（元チャンネルと同じ誠実さ）
- 最後にハッシュタグ3〜5個
- **論文の情報は投稿前に原文で確認する**（巻・号・ページ）

**サムネイル**
- 作り方：① Midjourney で**文字なしの絵**を作る → ② その絵を ChatGPT に渡して**文字だけ入れてもらう**
- 見た目の統一：4階建てのビルを縦に切った断面図（ミニチュア模型風）＋紺の方眼紙の背景＋1つの階だけアンバー色に光る
- 文字：上に「問い」（白の太字、紺の縁取り、キーワードだけアンバー）、下に「〇〇別｜人生の断面図」（チャンネル名を毎回入れて、シリーズだと分かるようにする）
- 元チャンネルの「〇〇別 視えている世界」と同じ文言・赤黒の配色は使わない（似すぎないため）
- ショートのサムネを自分で用意した画像にできるかは、YouTube の仕様が変わりやすい。**投稿するときに YouTube アプリで確認**する。できない場合も、同じ画像を長尺版やコミュニティ投稿に使える

### Midjourney の使い方のコツ
- 5本とも、下の**共通部分**の後ろに、各回の**部屋の中身**をつなげて入れる
- 1本目でいちばん良い絵ができたら、その画像を**参照画像（スタイル参照 `--sref`）**として2本目以降に付けると、絵の雰囲気がそろう
- 文字は Midjourney では入れない（日本語が崩れるため）。上の3分の1は文字を入れる場所として空けてもらう

**共通部分（英語のままコピー）**
```
vertical cutaway cross-section of a narrow four-story building, architectural miniature diorama, each floor is a small detailed room seen from the front, warm soft interior lighting, clean modern illustration, navy blue blueprint grid paper background with thin white technical drawing lines and dimension arrows, empty navy space in the upper third of the image for a title, high detail, tilt-shift,
```
**共通の末尾**
```
--ar 9:16 --v 7 --style raw --no text, letters, words, watermark, logo
```

### ChatGPT への頼み方（文字入れ）
Midjourney の画像を添付して、各回の「ChatGPT への指示」をそのまま貼る。
- 日本語の文字がまれに崩れるので、**1文字ずつ確認**する。崩れたら「〇〇の文字が違います。正しくは『…』です。ほかは変えずに直してください」と頼む
- 何度やっても崩れる場合は、Canva で文字だけ重ねる（フォントは太めのゴシック）
