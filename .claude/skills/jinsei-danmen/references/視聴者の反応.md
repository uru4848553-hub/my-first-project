# 視聴者の反応（コメント・数字）と、そこから直したこと

新しいコメントや数字が来たら上に足す。観測（事実）と、そこから決めたルールを分けて書く。

## 2026-11-25 ショート3「同じ迷路、4つの景色（IQ別）」

**観測**
- コメント「迷路の設計がよくわからん」（いいね3、投稿から約22時間）。チャンネルから「コメントありがとうございます。分かりやすくしますね！」と返信済み
- 投稿時点の登録者2人。いいねが付いたので、同じように感じた人が複数いる

**原因（動画を見直して分かったこと）**
1. 各階の枠＝「その人に見えている迷路の範囲」だと、ナレーションでもテロップでも言っていない。説明はスマホでは読めない小さな注記「見えているのは、ここまで」だけ
2. 1階は空の枠、2階は線2本…と、同じ迷路の一部ではなく別々の迷路に見える
3. スタート・ゴール・本人の位置がなく、迷路だと分かる目印がない
4. ビルの階と迷路の2つのたとえを重ねていて、関係が分かりにくい

**決めたこと**（SKILL.md 5章「絵は説明なしで分かること」）
- たとえは1本に1つ、1回は言葉ではっきり言う
- 同じものの見え方の差は「全体を1回見せる→各階は同じ絵を隠す・明かす」
- 何の絵か分かる目印（スタート・ゴール・自分の位置、軸と単位）を入れる
- 文字は最小40px。音を消して1場面1秒で何の絵か言えるかで確かめる

**同じ心配がある回**：ショート9（ちょっとした知り合い）の点線の図、ショート8の棒グラフ（「高さはイメージ」の小さな注記）
