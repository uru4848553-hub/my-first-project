# 使用済みの研究・データ一覧

新しい台本で研究を選ぶ前に、ここと照らし合わせる。**元チャンネル（夜ふかし解剖室）で使われたものは使わない**（中身の写しになるため）。自分のチャンネルで使ったものは、同じ研究を続けて使いすぎないよう記録する。

## 夜ふかし解剖室で使われたもの（使わない）

### 1位「なぜお金は、お金のあるところに集まるのか」
- アメリカ：所得の低い家庭のトイレットペーパーの買い方（まとめ買いできず節約の約半分が消える）
- カナダ：宝くじ当選者の近所で自己破産が増える
- フランス：2002年の失業手当の制度変更で起業が約25%増える
- アメリカ：7,000万人以上の友達のつながり（Chetty ほか 2022, Nature）
- オランダ：研究費の審査でギリギリ受かった人とギリギリ落ちた人（8年後に2倍以上）
- アメリカ：クラウドファンディングで、くじで選んだ企画に最初の支援（39%→70%）
- 冒頭の数字：貯金が増えた割合（年収300万円未満13%、750万円以上45%）

### 2位「世代ごとに視えている景色は、どう違うのか」
- 動画の2倍速の学習実験（アメリカの大学生）
- 日本の大人約3,800人が思い出した学校の様子
- 不景気の年に社会に出た人ほど仕事の満足が高い（アメリカ）
- 物価の見込みは世代が見てきた値札で決まる（日本の家計の調査）
- 人は思ったより変わる（約2万人の研究）
- 若宮正子さん（81歳でアプリ開発）

### 「なぜ会社の大きさで、給料はこんなに変わるのか」
- 大企業と中小企業の1人あたりの稼ぎの差の内訳（学歴や経験で1割、設備で6割半ば）
- 稼いだお金のうち人件費に回す割合（小さな会社8割、大企業5割未満）
- 会社の大きさ別の仕事の満足（36%・32%・37%）
- ソニーの始まりと設立趣意書

## のら学者で使われたもの（同じ組み立てでは使わない）
- 65歳以上の男の一人暮らし（2020年7人に1人→2050年4人に1人）
- 年金で暮らす65歳以上の一人暮らしの家計（月約3万円の赤字）
- 60歳以上で家族以外の親しい友人がいない割合（日本は3人に1人、男は約4割）
- 孤立死の推計（2025年約2万2千人、男は女の約4倍）
